# ГРАММ.io

2D survival-io для Android: вид сверху, джойстики, рубка деревьев, камни,
верстак, стены, Томпсон, базука, скины, монеты, лидерборд и онлайн.

Написано на Kotlin без единой внешней библиотеки (даже MQTT-клиент свой).
Собирается в APK через GitHub Actions.

## Скачать

APK лежит в [Releases](https://github.com/kirilltitov777z-dotcom/gramm-io/releases).

## Управление

- **левый джойстик** — ходить;
- **правый джойстик** — целиться и стрелять (удар/рубка тоже им);
- **хотбар** — кулаки, топор, кирка, Томпсон, базука, аптечка;
- **круглые кнопки справа** — стена (12 дерева) и верстак (25 дерева + 15 камня);
  рядом с верстаком кнопка делает 2 ракеты (15 дерева + 10 камня);
- **меню слева сверху** — пауза/выход;
- деревья дают дерево (топор), камни — камень (кирка), ящики — монеты,
  патроны и аптечки. Бочки взрываются.

## Онлайн

5 миров = 5 MQTT-топиков `grammio/v1/s0…s4` на публичном брокере
`broker.emqx.io` (резерв: `test.mosquitto.org`, `broker.hivemq.com`).
Аккаунт и пароль хранятся только на телефоне (SHA-256 + соль), а состояние
игрока летает по сети 8 раз в секунду. Боты добавляют движуху, если в мире
пока никого нет.

Вайпы:
- серверы 1–3 — раз в месяц;
- сервер 4 — раз в 2 месяца;
- сервер 5 — раз в неделю.

## Сборка

```bash
gradle :app:assembleDebug
```

или пуш в `main` — Actions сами соберут APK.
